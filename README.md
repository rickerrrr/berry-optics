## Next Step: Generate Visual Code

All non-visual work is done. The visual layer (UI components, pages, styles, 3D scenes) must be generated by Claude or GPT.

**Instruction file**: `generation-prompt.md` — contains complete specifications for each component, design system, data interfaces, and generation directives.

### How to use generation-prompt.md

1. Open the file in your AI coding assistant (Claude Code, Cursor, etc.)
2. Or copy its content as a prompt to Claude/GPT
3. The AI model will generate all files in `src/components/` and update `src/app/page.tsx`
